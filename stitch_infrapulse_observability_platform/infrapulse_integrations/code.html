Zero Raw Secrets Policy

InfraPulse never stores raw API tokens, client secrets, or private keys in plaintext. All connector secrets are envelope-encrypted with AWS KMS Key ARN:

arn:aws:kms:us-east-1:182909402:key/c402-990a-infrapulse-secrets-master

Decryption occurs in ephemeral secure memory during outgoing network calls and is wiped immediately upon socket close.
