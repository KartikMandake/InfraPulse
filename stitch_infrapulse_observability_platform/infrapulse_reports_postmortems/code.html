01 Executive Summary & Root Cause Analysis

Class: Resource Saturation Cascade

On Thursday, October 24, 2024, at 14:35 UTC, payment-service experienced severe thread starvation across its primary checkout ingress path, leading to an immediate drop in order processing and returning HTTP 504 Gateway Timeouts to 1,840 customer sessions.

Ground Truth Mechanism

Canary deployment v2.14.1 merged an unverified application configuration PR (#841) that intentionally lowered HikariCP maximumPoolSize from 80 to 20 under the assumption of reducing idle PostgreSQL worker processes.

Contributing Multiplier

Traffic coincided with a scheduled promotional blast at 14:35 UTC (+310% QPS). With pool clamped at 20, active worker threads blocked waiting on available database sockets, cascading upstream to API gateway circuit trips within 70 seconds.
